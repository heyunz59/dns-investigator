签名检查使用成熟库，不自写密码学。DO/AD、AA、Root Hints、服务器 EDE 均不构成本程序 DNSSEC 认证。局部 V 可以失败或缺材料；整体状态必须结合已建立的可信上下文。SECURE 只覆盖本次具体答案/必要证明，不表示所有 NS、全部地址或未来均正常。INSECURE 必须有认证的无 DS 委派证明。未知、超时、锚过期、策略不支持不随意记 BOGUS。

## 未支持与实际受限项

- 自动 CNAME 全链 DNSSEC 验证、DNAME、NSEC empty-nonterminal NODATA、Compact Denial/NXNAME 未实现；明确 capability_limited/INDETERMINATE。trace 可以独立跟随有界跨区 CNAME，二者不能混称。
- NSEC3 非零迭代、非空 salt、Opt-Out 安全判定，以及策略之外算法/密钥尺寸不支持。不会将其自动判 SECURE/INSECURE/BOGUS。
- 外部 NS 依赖可能形成跨区循环。当前不采用区外 Additional 偷渡引导，也不回退递归；因此某些正常公网结构仍不能完成。cloudflare.com 抽查分别停止于依赖预算或网络执行错误，不是已证明该域故障。
- 同机托管的 signer 提示仅支持可由已到达父区直接认证 DS 的边界。若缺少证明或中间区未建立，保守 INDETERMINATE；与成熟验证器可能不同，见下表。
- 仅检查有上限的选中 NS/地址和一次查询，不是全 NS 一致性验证、完整迭代缓存解析器或专业完整 DNSSEC 验证器。
- 未实现 RFC5011 守护。锚采用认证导入/受信软件分发，最大快照年龄180天；过期 fail closed。CMS 离线验证未做吊销检查，固定 ICANN CA pin 的变更仍需可信软件维护。
- 未做独立人工盲评、未见 holdout、长期网络覆盖、Linux 远程 CI。测试数据及复核均由开发助手制作/执行；自动检查不是语义准确率。

## 请求、计算与证据

所有 DNS 均经现有 DNSClient。外层 A、每次实际 UDP/TCP Q、有效测量 E、本地验证 V 分开。TC 的 UDP 和 TCP 各有 Q/E；超时 E 的 dns_rcode=null；取消未收到报文不能伪造响应。显式 parent_tool_call_id 和任务上下文保留并发归属，不使用全局列表末项推断。

默认10次工具尝试、32次实际 DNS 请求、单次 DNS≤5秒、复合总时间20秒；可由本地可信配置在原范围内调整。深度16、每层最多3台（默认2）、每 NS 两个地址、依赖深度4/总16、别名8。RRsets≤512、记录≤2048、验证输入≤2MB、DS/密钥候选各≤16、签名尝试≤64、总工作单位≤512。NSEC3 仅固定低成本参数。验证在可终止子进程，最多4秒；超时/取消 terminate、join，必要时 kill，不仅仅取消等待线程。外层总预算同时约束采集和验证。

同次引擎缓存按模式/区域/问题/服务器区分，仅复用原 E、注明用途和 TTL，不增加 Q/E；不保证跨工具调用合并。原始报文分区和 RRSIG 保留在 E，V 不伪装为网络 E。材料必须同来源、有效带时区采集时间、同问题/类/原查询上下文、DNSSEC DO/RD 参数。对同机托管保留原父侧查询上下文，不改写 E 为子区测量。

日志升为 v7，增加 Q 有效参数/时间、EDNS/EDE、protocol_investigations、validation_results、Finding 来源/严重性/验证引用。旧模型新增字段有默认值，现有读取适配不改写历史日志；旧记录缺 V/有效参数，不能补猜已验证。

## 验证结果

基线 **271 passed in 11.93s**，最终业务源码 **351 passed in 23.66s**，当前 Windows 环境无 skip，包含 IPv6 回环、旧并发归属/CNAME/调用统计/不可重试回归。新增80项为 EDNS7、trace14、DNSSEC39、边界16、协议报告4。`pip check` 无依赖冲突。PowerShell 7/.NET 的实际 CMS 导入测试在当前 Windows 执行通过；无该依赖的平台明确 skip 此集成测试，不模拟通过。

签名测试服务是真实回环 UDP/TCP，不是 fixture 字典；实验根/地址策略/测试锚只由测试程序注入。聚合 fixture 的 trace/dnssec 明确拒绝，不会回退公网。基线及所有失败/中间实验均保留。

独立参考使用官方 Windows 便携 **Unbound1.26.2**，二进制下载 URL、SHA256、版本保存，HTTPS 下载但未额外验 PGP。运行自己的 iterator+validator/OpenSSL，测试根锚/验证时刻与项目相同；固定时钟且签名 skew=0，项目算法策略更窄。参考用独立进程和独立回环请求，不计入项目 Q，也不是运行时依赖。

`reference-9bd82d9.json` 共35例：30个声明核心/材料完整场景与参考状态一致；该固定开发集未观测到错误 SECURE/BOGUS。不是一般准确率。5个边界：

|案例|项目|独立参考|解释|
|---|---|---|---|
|NSEC3 iterations100（有效构造）|INDETERMINATE|SECURE|项目明确的低成本策略限制|
|Opt-Out|INDETERMINATE|INSECURE|未实现 Opt-Out 安全语义|
|算法16 Ed448|INDETERMINATE|SECURE|不在本阶段算法策略中|

普通类型的正例另外有单元/受控集成测试；独立参考主矩阵针对 A，不把它扩大为全部类型参考覆盖。初次 Unbound 的 Unicode 路径、根引导失败、测试服务器漏处理补查 DS 等均保留；不是通过结果。初次本机端口偶发失败定位为 UDP 端口被选为 Windows TCP 禁止端口，测试服务改为先预留 TCP 再绑定 UDP，有限重选并完整清理。

## 证据关系样例与复测

受控正常链：A1 的 Q1/E1 根转介、Q2/E2 父转介、Q3/E3 子区 AA 目标；随后 E4 根 DNSKEY、E5 父 DS、E6 父 DNSKEY、E7 子 DS、E8 子 DNSKEY。V1根DS匹配→V2根密钥集→V3父DS→V4匹配→V5父密钥集→V6子DS→V7匹配→V8子密钥集→V9目标签名。原始 Q/E/V 的具体编号以该 run 为准，不能套用到另一场景。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m dns_investigator.main "请从根开始独立追踪 nic.cz 的 A 委派路径"
.\.venv\Scripts\python.exe -m dns_investigator.main "请直接验证 nic.cz 的 A 记录 DNSSEC 信任链"
.\.venv\Scripts\python.exe -m evaluation.protocol_public_capture results/runs/new-public-sample.json --domain nic.cz
```

后3条会访问真实网络，CLI Agent 还消耗 DeepSeek 额度，结果可随网络/时间变化。网络过滤、循环引导、预算不足可合法停止。没有密钥仍可运行协议单元/受控服务与纯工具采样。

锚更新由维护者从 `https://data.iana.org/root-anchors/` 单独取得 XML、p7s、ICANN bundle，到与活动 assets 不同的目录，再执行：

```powershell

```

需 PowerShell7/.NET。输入≤64KiB；固定软件 CA pin，不接受导入目录自报 pin。先验 detached CMS、固定 CA 链/当前证书时效、XML锚/有效期，再安装；认证失败不动旧快照，安装失败回滚。不是 Agent 参数，不是 RFC5011。没有自动下载替换或关闭验证的降级。
